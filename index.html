Selected work

SiteCheck AI — LLM site audit with a deterministic fallback

Applied AI · TypeScript

Crawls a site with Puppeteer, runs it through an LLM and returns a plain-language audit as a PDF. The site being audited is attacker-controlled text, and it was reaching the prompt raw — so I hardened that structurally, then wrote the negative evals that prove it, because delimiters only hold if the model respects them. 12 fixtures, structured traces, CI gates that run offline, and a rule-based path that keeps the product working when the model is down. The suite is mutation-tested: one that only goes green proves nothing. This is the repo I would walk through end to end.

triage-agent — issue triage, instrumented first

Applied AI · TypeScript · in progress

Classifies issues from a busy open source repo and escalates instead of drafting when it should not decide alone. The evals and the collector were built before the model path, which is still a skeleton: a classifier is easy to demo and hard to trust. Running it against the real GitHub API showed my own threshold escalates half of real traffic — recorded, not tuned away.
